# CODIORA Freelancing Marketplace (Week 7)

## Run
1. Extract the ZIP folder.
2. Open the `codiora_marketplace` folder.
3. Double-click `index.html` or right-click it and open with Chrome/Edge.
4. No npm install or server is required.

## Included
- Responsive marketplace home page
- Search across service title, freelancer, category and skills
- Multi-filter search: category, min/max price, rating, delivery time, experience
- Sorting: popularity, price ascending/descending, rating, newest
- Favorites saved in browser LocalStorage
- Client and Freelancer dashboard views (switch using the top-right selector)
- Job listing search, post a job, submit proposal (demo)
- Service detail modal, contact seller demo, create order
- Orders/projects with status tabs and progress
- Messages empty state, notifications and mark-as-read
- Marketplace statistics and responsive layouts

## Important
This is a frontend academic demo. Data is stored in the browser using LocalStorage.
It does not include a real backend, authentication, payment gateway, or real-time messaging.
